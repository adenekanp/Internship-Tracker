# Internship Tracker

## Overview
A web-based application to help students track internship applications, deadlines, and statuses efficiently.

## Features
- User authentication with Identity
- Add, edit, and delete internship applications
- Status tracking and reminders
- Search, filter, and sort applications
- Dashboard with upcoming reminders
- RESTful API support for applications

## Technologies Used
- ASP.NET Core MVC
- Entity Framework Core
- JavaScript & AJAX (for asynchronous status updates)
- Identity (Authentication)
- SQL Server
- Bootstrap & jQuery
